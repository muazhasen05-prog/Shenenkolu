# የአስተዳዳሪ መመሪያ — አማርኛ

## የሸነን ኮሉ ወረዳ ብልጽግና ፓርቲ ይፋዊ መረጃ መድረክ

እንኳን ወደ ሸነን ኮሉ ወረዳ ብልጽግና ፓርቲ ድረ-ገጽ እና የPWA መተግበሪያ ይፋዊ የአስተዳደር መመሪያ በደህና መጡ።

---

## 1. የመጀመርያ የአስተዳዳሪ ምዝገባ እና አገባብ

### 1.1 የመጀመሪያውን ሱፐር አድሚን (Super Admin) ማዋቀር
የመጀመሪያውን የሱፐር አድሚን መለያ ያለ ክፍተትና ደህንነቱ በተጠበቀ ሁኔታ ለማዘጋጀት፡

1. በ `.env.local` ፋይል ውስጥ የሚከተሉትን መረጃዎች ያዘጋጁ፡
   ```env
   INITIAL_ADMIN_EMAIL="admin@shenenkolu.gov.et"
   INITIAL_ADMIN_PASSWORD="YourStrongPassword123!"
   INITIAL_ADMIN_FULL_NAME="ዋና የስራ አስፈጻሚ አስተዳዳሪ"
   ```
2. በተርሚናል ውስጥ ትዕዛዙን ያሂዱ፡
   ```bash
   npm run bootstrap:admin
   ```
3. ስክሪፕቱ በSupabase Auth ውስጥ ተጠቃሚውን ፈጥሮ በ `profiles` ሠንጠረዥ ውስጥ የ `super_admin` ሚናን በይፋ ይመድባል።

### 1.2 ወደ ዳሽቦርድ መግባት
- በአሳሽዎ ይክፈቱ፡ `https://your-domain.com/am/auth/login`
- የተመዘገበውን የኢሜይል አድራሻ እና የይለፍ ቃል በማስገባት ይግቡ።
- ከመግባትዎ በኋላ ከላይ ባለው ማውጫ ላይ **ዳሽቦርድ** ወይም በቀጥታ `/admin` የሚለውን ይጫኑ።

---

## 2. የዜና እና መግለጫዎች አስተዳደር (`/admin/news`)

ይህ ክፍል የተረጋገጡ የወረዳ የልማት ዜናዎችን፣ የግብርና ሪፖርቶችን እና ይፋዊ መረጃዎችን ለማተም ያገለግላል።

### 2.1 አዲስ ዜና ማተም
1. ከግራ በኩል ባለው ማውጫ ላይ **የዜና አስተዳደር** &rarr; **አዲስ መዝግብ** (`/admin/news/new`) የሚለውን ይምረጡ።
2. **የቋንቋ ትሮች (Multilingual Tabs):**
   - **English:** የእንግሊዝኛ ርዕስ፣ አጭር ማጠቃለያ እና ሙሉ ዜናውን ያስገቡ።
   - **Afaan Oromoo:** የኦሮምኛ ርዕስ፣ ማጠቃለያ እና ሙሉውን ጽሁፍ ያስገቡ።
   - **አማርኛ:** የአማርኛውን ርዕስ፣ ማጠቃለያ እና ሙሉውን ይዘት ይጻፉ።
3. **ዘርፍ (Category):** የሚመለከተውን የወረዳውን የልማት ዘርፍ ይምረጡ (ለምሳሌ፡ *የግብርና እና ገጠር ልማት*፣ *የውሃ እና መሠረተ ልማት*)።
4. **የፊት ገጽ ምስል (Cover Image):** የዜናውን ሽፋን ምስል ሊንክ ያስገቡ።
5. **የህትመት ሁኔታ (Status):**
   - **Published (የታተመ):** ወዲያውኑ ለህዝብ ክፍት ሆኖ ይታያል።
   - **Draft (ረቂቅ):** በውስጥ ደረጃ ለግምገማ ብቻ ተቀምጦ ይቆያል።
6. **የቀጥታ ማሳወቂያ መላክ:** መተግበሪያውን የጫኑ ነዋሪዎች ወዲያውኑ መረጃው እንዲደርሳቸው **Send Web Push Alert** የሚለውን ያብሩ።
7. **Publish Article** የሚለውን በመጫን ያትሙ።

## 3. ህዝባዊ ማስታወቂያዎች (`/admin/announcements`)

ማስታወቂያዎች አስቸኳይ የአስተዳደር ጥሪዎች እና መመሪያዎች ናቸው።

### 3.1 መደበኛ እና አስቸኳይ ማስታወቂያ (Priority)
- **Normal (መደበኛ):** በማስታወቂያዎች ገጽ ላይ በመደበኛ መልኩ ይታያል።
- **Urgent (አስቸኳይ):** በሁሉም ገጾች አናት ላይ ደማቅ ቀይ የማስጠንቀቂያ ባነር በማብራት ለህብረተሰቡ ፈጣን መረጃ ይሰጣል (ለምሳሌ፡ የህፃናት ክትባት ጥሪ፣ ድንገተኛ የአየር ጠባይ መግለጫ)።

### 3.2 የማብቂያ ቀን ማስቀመጥ (Expiration Date)
- ጊዜያዊ ማስታወቂያዎች ላይ **የሚያበቃበትን ቀን** ይምረጡ። ቀኑ ሲያልፍ ስርዓቱ ወዲያውኑ ከህዝብ እይታ ያነሳዋል።

## 5. የቀጥታ የበይነመረብ ስብሰባዎች (`/admin/meetings`)

LiveKit WebRTC ቴክኖሎጂን በመጠቀም የቀጥታ የድምጽ እና ምስል ስብሰባዎችን ያለ ምንም ወርሃዊ ክፍያ ($0/ወር) ለማካሄድ ያገለግላል።

### 5.1 አዲስ ስብሰባ ማዘጋጀት
1. **Meetings & Forums** &rarr; **Schedule Meeting** (`/admin/meetings/new`) ይጫኑ።
2. ርዕስ እና አጀንዳውን በሦስቱም ቋንቋዎች ያስገቡ።
3. **የመለያ ኮድ (Room ID):** የእንግሊዝኛ ፊደላትና ቁጥሮችን የያዘ መለያ ይስጡ (ለምሳሌ፡ `shenen-kolu-forum-2026`)።
4. **የመግቢያ ፈቃድ (Access Policy):**
   - **Open to Public:** ሊንኩ ያለው ማንኛውም ዜጋ በቀጥታ መሳተፍ ይችላል።
   - **Members Only:** የተመዘገቡ አባላት ብቻ በመለያቸው ገብተው ይሳተፋሉ።
   - **Restricted:** በግብዣ ብቻ።

### 5.2 የአዘጋጅ አስተዳደር (Host Controls)
- ስብሰባውን የሚያዘጋጁ አመራሮች፡
  - **Mute All:** የሁሉንም ተሳታፊዎች ድምፅ በአንድ ጊዜ መዝጋት ይችላሉ።
  - **Share Screen:** ሰነዶችንና አጀንዳዎችን ለተሳታፊዎች ማሳየት ይችላሉ።
  - **End for All:** ስብሰባውን ለሁሉም ተሳታፊዎች በአንድ ጊዜ ማጠናቀቅ ይችላሉ።

## 6. የአባላት እና ሚናዎች አስተዳደር (`/admin/users`)

*በሱፐር አድሚን ብቻ የሚከናወን።*

- `super_admin`: ሙሉ የስርዓት አስተዳደር እና የፈቃድ መቆጣጠሪያ።
- `editor`: ዜናዎችን፣ ማስታወቂያዎችን እና ፎቶዎችን ማተም እንዲሁም ማሳወቂያዎችን መላክ።
- `moderator`: የቀጥታ ስብሰባዎችን ማስተባበር እና መምራት።
- `member`: በስብሰባዎች ላይ የሚሳተፉ የተመዘገቡ ነዋሪዎች።
